# 前端改造 M1：状态栏改用同步数据

日期：2026-11-14（Asia/Shanghai）。分支 `blue-topaz-stats`，基于 `frontend-baseline`。

## 背景

桌面端的状态栏原先在 app 树之外单独渲染，靠 10 秒轮询 `GET /api/session/:id` 取 token，会话 ID 从 localStorage 的 `last-active-url` 里正则解析，历史消息还用 V1 的 `info.role/parts` 解析（V2 已改成 `type/text`，实际恒为空）。

## 改动

- 新增 `packages/app/src/blue-topaz/`：`session-stats.tsx` 读客户端已同步的 `server.ctx.data.session.get(id).tokens`；`stats-format.ts` 保留原口径（K/M 缩写、缓存命中 = read / (read + write + input)）。
- 挂载在 composer lane（`session/composer/region.tsx`），条件为桌面端、非 HUD、非子会话。
- 文案走 i18n（`session.stats.*`），不再硬编码中文，也不再使用字面字体族。
- 桌面端删除：10 秒轮询、HTTP 轮询、路由正则解析、V1 解码、粘性徽章/序列条残留、`bt.debug.v1`、约 150 行死 CSS；`blue-topaz-widgets.tsx` 只保留每轮折叠思考按钮。

## 验证

- `packages/app` 与 `packages/desktop` 的 `bun check`：无类型错误。
- `stats-format.test.ts`：3 pass（K/M 边界、缓存命中口径、分母为 0）。
- `lint:changed`：本次改动的文件无告警（其余告警来自更早提交的既有文件）。
- 桌面 renderer 已无 `fetch`/`setInterval`/`localStorage` 使用点（启动流程除外）。

## 未做

- **视觉未验证**：需要另起桌面实例，而源码版与安装版共用 `APP_ID`，不能双开。
- 折叠思考按钮仍是命令式 DOM（脱离 Solid 树、`document.body` 观察者、按钮文案硬编码中文）。它依赖虚拟化行的坐标，改成树内渲染需要动 `session-ui` 的行渲染接口，另立一项。
- 状态栏外观从“输入框左侧竖排”改为 composer 上方一行紧凑文本。
