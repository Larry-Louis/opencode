# 前端改造 M1：状态栏改用同步数据

日期：2026-11-14（Asia/Shanghai）。分支 `blue-topaz-stats`，基于 `frontend-baseline`。

## 背景

桌面端的状态栏原先在 app 树之外单独渲染，靠 10 秒轮询 `GET /api/session/:id` 取 token，会话 ID 从 localStorage 的 `last-active-url` 里正则解析，历史消息还用 V1 的 `info.role/parts` 解析（V2 已改成 `type/text`，实际恒为空）。

## 改动

- 新增 `packages/app/src/blue-topaz/`：`session-stats.tsx` 读客户端已同步的 `server.ctx.data.session.get(id).tokens`；`stats-format.ts` 保留原口径（K/M 缩写、缓存命中 = read / (read + write + input)）。
- 挂载在 composer lane（`session/composer/region.tsx`），条件为桌面端、非 HUD、非子会话。
- 文案走 i18n（`session.stats.*`），不再硬编码中文，也不再使用字面字体族。
- 桌面端删除：10 秒轮询、HTTP 轮询、路由正则解析、V1 解码、粘性徽章/序列条残留、`bt.debug.v1`、约 150 行死 CSS；`blue-topaz-widgets.tsx` 只保留每轮折叠思考按钮。

## 验证

- `packages/app` 与 `packages/desktop` 的 `bun check`：无类型错误。
- `stats-format.test.ts`：3 pass（K/M 边界、缓存命中口径、分母为 0）。
- `lint:changed`：本次改动的文件无告警（其余告警来自更早提交的既有文件）。
- 桌面 renderer 已无 `fetch`/`setInterval`/`localStorage` 使用点（启动流程除外）。

## 未做

- **视觉未验证**：需要另起桌面实例，而源码版与安装版共用 `APP_ID`，不能双开。
- 折叠思考按钮仍是命令式 DOM（脱离 Solid 树、`document.body` 观察者、按钮文案硬编码中文）。它依赖虚拟化行的坐标，改成树内渲染需要动 `session-ui` 的行渲染接口，另立一项。
- 状态栏外观从“输入框左侧竖排”改为 composer 上方一行紧凑文本。

## 后续（本轮已继续）

M2：轮次导航与正文分页解耦（导航不可见时不预读历史），以及主窗/HUD 同会话双开时的请求放大观测。

# 同日续：M2 与 M3

## M2：导航历史按需加载

- 打开会话不再补读最多 12 页历史；只有指针进入轮次导航或键盘聚焦某个点时触发补读。
- 同一会话只触发一次，离开会话取消在途请求。
- 回归测试：`e2e/regression/timeline-history.spec.ts` 新增「pages older turns only when the reader reaches for the navigator」。
  - 修复前版本在该用例上失败（多出 `before=older` 请求），修复后通过。
  - `timeline-history.spec.ts` 全文件 11 个用例通过。

## M3：HUD 运行状态改为直传

- 新增 `packages/app/src/hud/hud-working.ts`：HUD 内部的运行状态通道（frame 位于 ServerProvider 之上，读不到会话数据）。
- `session/screen.tsx` 在 HUD 模式把 `session.data.working()` 直接发布；
- `hud-frame.tsx` 订阅该通道，不再观察 `data-hud-transcript-working` 属性，MutationObserver 也不再监听属性变化。
- 1.1 秒保温与 holdUntilFocus 逻辑未变。

## 折叠思考按钮迁入时间轴

- 删除 `blue-topaz-widgets.tsx`、`blue-topaz-host.ts` 及其挂载（约 290 行）。
- 按钮改为由时间轴渲染：按投影里每个已结束且思考仍展开的轮次，取该轮最后一行的虚拟位置计算坐标，直接从虚拟项计算，不测量 DOM、不观察 DOM。
- 文案走 i18n（`session.thinking.collapse`），只在桌面端显示（`platform.platform === "desktop"`）。
- 代价：按钮样式从 RGB 手写改为设计 token，外观会与原来略有差异。

## 验证（本轮）

- `packages/app` / `packages/desktop` 的 `bun check`：无类型错误。
- `timeline-history` + `session-timeline-tool-projection` e2e：13 个用例通过。
- 新增单测 `stats-format.test.ts` 3 个用例；`lint:changed` 中本次改动文件无告警。
